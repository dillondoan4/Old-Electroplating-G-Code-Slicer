This python script is the old version of the g-code slicer used in my electroplating research at Widener University. The program searches for .gcode files and asks the user to select which one is the main (the one to be printed in Conductive PLA) and which one is the copper path (the area or path that will be copper plated). Afterward, the program will ask for the user to input the plating parameters. Finally, the program merges the two files into one .gcode package.
